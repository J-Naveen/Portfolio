2025 – Present · Chennai

I am responsible for the security testing of web, API and mobile applications for enterprise clients, covering OWASP Top 10 issues such as XSS, SQL injection, XPath injection and improper server-side validation. I run automated vulnerability scans, validate findings, and raise and track defect tickets.

I work closely with developers to explain root causes, recommend code-level fixes and retest to confirm closure, and I join client calls to explain issues that cannot be reproduced. An XSS fix guided by my testing helped a client site go live within hours.

I have completed security testing of multiple application modules and delivered the reports on schedule. I have bypassed root detection and SSL pinning in mobile apps with custom Frida scripts, and I now test AI/LLM applications with Garak, PyRIT and Promptfoo, using Python scripts I wrote.
